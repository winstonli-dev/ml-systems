The notebook now compares five feature sets: the baseline 8, baseline plus transport (12),
baseline plus chunk detail (10), combined (14), and all traffic (161).

measurements listed below, with `L7_n_chunks_down` replaced by `segment_download_rate = L7_n_chunks_down / 10`.

remain separate from this labeled dataset's chunk-IAT features.
